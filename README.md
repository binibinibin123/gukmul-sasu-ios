# 국물 사수! / Hold the Broth! — iOS build

Xcode project exported from the Godot 4.7.2 game (game data in `GukmulSasu.pck`).
The Godot engine libraries are downloaded at build time from the official Godot release.

`Actions → iOS App Store build → Run workflow` archives, signs (App Store Connect API key,
automatic signing) and uploads to App Store Connect / TestFlight.
